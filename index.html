01 Projeto em equipe Full-stack MVC

Petshop Spring MVC

E-commerce de pet shop com catálogo, carrinho, pedidos e área administrativa.

Problema
Uma loja precisa vender online e administrar o próprio catálogo, com controle de acesso por perfil — sem manter um front-end separado.
Como foi resolvido
  • Páginas renderizadas no servidor com Spring MVC + Thymeleaf; produtos, imagens, pedidos e usuários persistidos com Spring Data JPA no PostgreSQL.
  • Autorização declarativa com Spring AOP: as anotações @VerifyIfLogged e @VerifyIfIsAdmin interceptam os controllers através de aspects.
  • Senhas com hash BCrypt, login por sessão HTTP e carrinho serializado em JSON num cookie HttpOnly.
  • Upload de várias imagens por produto e um DataSeeder (CommandLineRunner) que cria o admin e o catálogo na primeira execução.
  • Java 21
  • Spring Boot 3.5
  • Spring MVC
  • Spring Data JPA
  • Spring AOP
  • Thymeleaf
  • PostgreSQL
  • Docker Compose
  • Tailwind

02 Em desenvolvimento Projeto pessoal

Tasks API

API REST de tarefas gamificada, construída para praticar Clean Architecture de verdade.

Problema
Organizar tarefas com prazo, status e tags, recompensando o usuário com moedas ao concluí-las — mantendo as regras de negócio independentes de framework e banco.
Como foi resolvido
  • Três camadas isoladas: domain (entidades puras, sem anotações), application (use cases + gateways) e infra (controllers, JPA, mappers).
  • O núcleo não conhece o Spring: os casos de uso são ligados por @Configuration/@Bean e o UserRepositoryGateway é implementado na infra.
  • Invariantes no domínio: a entidade User valida a senha no construtor (8+ caracteres, maiúscula, número e símbolo).
  • Erros centralizados com @RestControllerAdvice e ErrorResponse padronizado; IDs UUID e PostgreSQL via Docker Compose.
Status
Cadastro de usuários pronto e testado. Em andamento: consulta de usuário (GetUserUseCase), depois CRUD de tarefas e tags.

03 Projeto pessoal Arquitetura

Validating CPF · Hexagonal

Cadastro de clientes com Ports & Adapters, mensageria Kafka e integração HTTP.

Problema
Cadastrar clientes completando o endereço a partir do CEP e enviando o CPF para validação assíncrona — sem acoplar a regra de negócio a banco, HTTP ou mensageria.
Como foi resolvido
  • Arquitetura Hexagonal: os use cases dependem só de input/output ports; cada tecnologia vive num adapter substituível.
  • Spring Cloud OpenFeign consulta o serviço de endereço pelo CEP e o cliente é persistido no MongoDB.
  • O CPF é publicado no tópico tp-cpf-validation; um @KafkaListener no tópico tp-cpf-validated recebe o resultado da validação.
  • CRUD completo (POST, GET, PUT, DELETE) com Bean Validation nos requests e use cases injetados via configuração.
  • Java 21
  • Spring Boot 3.5
  • Hexagonal Architecture
  • Apache Kafka
  • MongoDB
  • OpenFeign

04 Projeto em equipe Faculdade

Voyager People Management

Sistema de gestão de pessoas: cargos, departamentos, ponto, visitantes e relatórios.

Problema
Centralizar a gestão de pessoas de uma empresa — funcionários, terceirizados e visitantes — com registro de ponto e relatórios exportáveis para o RH.
Como foi resolvido
  • Camadas Controller → Service → Repository com Spring Boot e views Thymeleaf com fragments reutilizáveis.
  • Histórico de cargos automático: ao trocar o cargo de alguém, o período anterior é encerrado e um novo registro é aberto.
  • Ponto para funcionários e terceirizados, crachá de visitante com código gerado e validações de negócio (idade mínima, datas coerentes, nome de projeto único).
  • Exportação de relatórios em CSV (OpenCSV) e PDF (Apache PDFBox); H2 para testes.

05 REST API

Image Lite API

Armazenamento e busca de imagens com metadados.

  • Upload multipart/form-data (até 20 MB) com nome e tags; arquivo salvo como @Lob no PostgreSQL e extensão inferida pelo MediaType.
  • Busca dinâmica com JPA Specifications: filtros opcionais combinados — extensão e (nome ou tags), sem diferenciar maiúsculas.
  • Semântica HTTP correta: 201 com header Location, download com Content-Type e Content-Length; data de upload via @CreatedDate.
